# Contributing

Contributions are welcome, and so is support for more third-party renderers and plugins. Anything
outside the project's scope, such as a user interface, will most likely be rejected.

3dsmax-mcp aims to be as renderer- and plugin-agnostic as it can.

Test your tools yourself in real-world scenarios instead of trusting an agent's passing "smoke
tests". 

Non-English PRs are rejected.

## Avoid unreadable PR requests.

You know I won't be reading the code, you won't read it too. So please write the PR yourself and intent clearly. 

See https://dontbeameatproxy.com/.
